# ID: CS34

Título: Las peticiones parciales del test omiten versión Inertia y reciben HTTP 409

Estado: Actual; omisión de encabezado observada; respuesta 409 confirmada

Prioridad: Alta

Severidad: Media

Encargado: Sin asignar

Clasificación: Automatización/protocolo Inertia; causa del 409 por cerrar con encabezados

## Descripción

query(...,true) envía X-Inertia y datos parciales sin X-Inertia-Version. Tres roles esperan 200 y el estudiante espera 403; los cuatro reciben 409. El helper omite el encabezado, pero el fragmento no aporta X-Inertia-Location ni la respuesta completa para probar que todos los 409 comparten causa.

Casos relacionados: HU13-02 personal de control/docente/administrador; HU13-03 estudiante.

## Precondiciones

Instancia income-e2e, base exclusiva app_e2e y puerto 8082. URL http://localhost:8082/; http://web dentro del runner. Fixtures independientes reset-hu13. Contraseña E2ePassword!2026. Cypress 16.1.1, Electron 146 headless y Node v22.0.0 según la cabecera aportada. Fecha/hora de inicio, sistema operativo y revisión de código no confirmados; no se atribuye Windows/Brave del ejemplo.

## Pasos y datos de entrada

| Paso | Acción | Datos de entrada |
|---:|---|---|
| 1 | Autenticarse con cada rol autorizado y abrir panel | Control, docente o administrador del fixture |
| 2 | Seleccionar Principal HU13 y consultar JSON | GET /panel-asistencia?id_examen={id_real}; Accept:application/json |
| 3 | Enviar consulta parcial como lo hace el test | GET misma URL; X-Inertia:true; X-Inertia-Partial-Component:Control/PanelAsistencia; X-Inertia-Partial-Data:ambientes,pendientes,resumen; sin X-Inertia-Version |
| 4 | Repetir comprobación de rechazo para estudiante | 202600901; se espera 403 en consulta parcial |

Resultado actual: HTTP 409 en vez de 200 para roles autorizados y en vez de 403 para estudiante.

Resultado esperado: Cliente de prueba compatible con la versión real Inertia; consulta parcial válida 200 para roles permitidos y rechazo 403 para estudiante, sin aceptar 409 como cumplimiento de permisos.
