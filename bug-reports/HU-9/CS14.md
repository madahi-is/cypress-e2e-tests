# ID: CS14

Título: Las pruebas de permisos se detienen en HTTP 419 antes de comprobar autorización

Estado: En investigación

Prioridad: Alta

Severidad: Por determinar

Encargado: Sin asignar

Clasificación: Causa pendiente; obstáculo CSRF/sesión en automatización

## Descripción

Docente, control y estudiante reciben 419 donde se espera 403. No demuestra acceso permitido ni incumplimiento del control de roles. El helper envía token meta, pero faltan método/URL exactos del primer 419, estado de cookies y token de sesión para identificar la causa.

Casos relacionados: HU09-02 docente/control/estudiante.

## Precondiciones

Instancia aislada income-e2e; base app_e2e; URL local http://localhost:8082/ (http://web dentro del runner). Fixtures independientes HU-9. Administrador admin.e2e@example.test, contraseña E2ePassword!2026. Cypress 16.1.1; Node v22.0.0; la salida identifica Electron 41.7.0 / Chrome 146 en Linux. No se usó el entorno Windows/Brave del ejemplo. Fecha exacta de inicio no suministrada; el fragmento HTTP contiene 15/10/2026 04:46 UTC.
