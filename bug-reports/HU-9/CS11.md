# ID: CS11

Título: El registro de grupos rechaza el formato de Gestión 2026-2

Estado: Actual; confirmado por ejecución y código

Prioridad: Alta

Severidad: Media

Encargado: Sin asignar

Clasificación: Incumplimiento funcional HU-9

## Descripción

El servidor restringe gestion a cuatro dígitos mediante /^\d{4}$/. La HU exige admitir 2026-2 o similar. Los cuatro registros UI no cerraron el modal y el caso directo devolvió 422. Cuatro pruebas adicionales usan la misma Gestión rechazada y no permiten concluir que fallen la unicidad, varios grupos por docente o el límite de 50 caracteres.

Casos relacionados: HU09-04 A/B/1A/14 y HU09-05; impacto probable, no causa individual confirmada: HU09-14 nombre/asignatura/gestion y HU09-15 50.

## Precondiciones

Instancia aislada income-e2e; base app_e2e; URL local http://localhost:8082/ (http://web dentro del runner). Fixtures independientes HU-9. Administrador admin.e2e@example.test, contraseña E2ePassword!2026. Cypress 16.1.1; Node v22.0.0; la salida identifica Electron 41.7.0 / Chrome 146 en Linux. No se usó el entorno Windows/Brave del ejemplo. Fecha exacta de inicio no suministrada; el fragmento HTTP contiene 15/10/2026 04:46 UTC.

| Paso | Acción | Datos de entrada |
