# ID: CS12

Título: Los IDs de texto provocan HTTP 500 al registrar o reasignar un grupo

Estado: Actual; respuesta 500 confirmada

Prioridad: Alta

Severidad: Media

Encargado: Sin asignar

Clasificación: Validación defensiva adicional; no criterio textual explícito HU-9

## Descripción

Tres casos reciben 500 en lugar de 422. El código contiene reglas integer/exists y consultas posteriores de User con la entrada original. Sin traza PHP/SQL no se afirma una causa interna única para los tres errores.

Casos relacionados: HU09-11 id_asignatura texto; HU09-11 id_usuario texto; HU09-25 texto.
